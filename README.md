## Описание проекта

Проект представляет собой прототип сервиса **Яндекс Музыка**, адаптированный под учебные требования контрольной работы №2. Интерфейс выполнен в фирменной тёмной графитовой палитре (`#121212`) с контрастными жёлтыми акцентами (`#ffcc00`), адаптивной 12-колоночной сеткой Bootstrap 5 и постоянным нижним плеером.

---

## Реализованные экраны и разделы

0. **Фиксированный нижний плеер** — persistent-панель воспроизведения с метаданными трека, прогресс-баром и регулятором громкости.
1. `index.html` — Главная страница (Hero-блок релиза, карточки хитов, промо-баннеры, alert).
2. `catalog.html` — Каталог жанров и главный чарт треков в виде адаптивной таблицы с badge-индикаторами.
3. `album.html` — Страница альбома (обложка, метаданные, треклист релиза).
4. `track.html` — Страница трека с аккордеоном (`accordion`) для текста песни и копирайтов.
5. `artist.html` — Профиль исполнителя (баннер, статистика слушателей, карточки дискографии).
6. `playlists.html` — Каталог тематических подборок ("Для тренировок", "В дорогу", "Фокус").
7. `playlist.html` — Страница выбранного плейлиста со списком композиций.
8. `profile.html` — Личный кабинет пользователя с вкладками (`nav-pills` / `tabs`) для сохранённых треков, плейлистов и любимых исполнителей.
9. `order.html` — Полноценная форма оформления подписки Яндекс Плюс и заказа мерча.

## Использованные компоненты Bootstrap 5

- **Сетка и контейнеры:** `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-3`, `g-4`.
- **Навигация:** `navbar`, `navbar-expand-lg`, `navbar-toggler`, `dropdown-menu`.
- **Карточки:** `card`, `card-header`, `card-body`, `h-100`.
- **Кнопки:** `btn`, `btn-warning`, `btn-outline-light`, `btn-sm`, `rounded-pill`, `rounded-circle`.
- **Значки:** `badge` («Хит», «Новинка», «18+», «Плюс», «Эксклюзив»).
- **Сообщения:** `alert`, `alert-dark`, `alert-warning`.
- **Модальное окно:** `modal`, `modal-dialog-centered` для быстрого подключения подписки.
- **Интерактивные вкладки и аккордеон:** `accordion`, `nav-pills` / `tab-content`.
- **Формы:** `form-control`, `form-select`, `input-group`, `input-group-text`, `form-check`.

---

## Способ подключения Bootstrap

Bootstrap подключён через CDN:

- CSS: `Bootstrap 5.3.3` + `Bootstrap Icons 1.11.3`
- JS: `Bootstrap Bundle 5.3.3` (перед закрывающим тегом `</body>`)
- Кастомные стили: `css/custom.css` (подключён после Bootstrap CSS)
- Данные: `js/data.js` (хранение объектов и реакция плеера на клики)
